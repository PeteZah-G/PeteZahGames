# Firefox WASM (vendored)

Large binaries are gitignored. After clone:

```bash
npm run vendor:firefox-wasm
```

Sources:
- https://developer.puter.com/labs/firefox-wasm/
- https://github.com/HeyPuter/firefox-wasm

Default network path: Virginia Wisp `/api/alt-wisp-3/` (override in Advanced options, e.g. `/wisp/`).
